# User Guide

1. Place ICICI Direct equity transaction statement PDFs in `data/statements`.
2. Place portfolio XLS/XLSX/TSV in `data/portfolio`.
3. Run `streamlit run app.py`.
4. Use tabs for Overview, Stock Analysis, Annual Performance, Benchmark Analysis, Gains & Dividends, Data Management.
5. Use sidebar filters for date range and stock status.

All metrics are computed by tested calculation services.
