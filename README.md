# ICICI Direct Portfolio Analyzer

A local-first Streamlit app for parsing ICICI Direct equity transaction PDFs and portfolio XLS/TSV files, reconstructing historical holdings, computing XIRR/TWR, benchmarking against Nifty TRI, and generating Excel reports.
